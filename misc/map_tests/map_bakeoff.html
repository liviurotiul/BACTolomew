Map renderer bake-off - 6 candidates

The same ST492 sample data (25 countries, ~160 points) rendered six ways. All six render in my sandbox because it has software GL; the real test is your machine, whose hardware GL is broken. The four marked safe use no OpenGL and cannot crash; the two Chromium-based ones are the risk.

Run this once on your machine - no app needed: python map_tests/test_maps.py

It runs each renderer in an isolated subprocess (a crash kills only that one), prints a ✅/💥 table, and writes PNGs to map_tests/out/. That tells us definitively which survive your GPU.
