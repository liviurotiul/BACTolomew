Pipeline overview

Why this layout is simpler

BACTolomew is easier to understand as a directed process than as a dense all-to-all network. The pipeline has two main biological jobs: infer cohort structure and recover contextualized gene or locus evidence. Those branches rejoin only when interpretation begins.

Compute fit

  • The main workflow begins from assemblies rather than forcing raw-read assembly inside the pipeline.
  • Heavier branches such as reference-based variant calling are optional rather than mandatory.
  • Targeted searches against curated databases are easier to run routinely than permanently maximal workflows.

Gene hits are not enough

Marker screening tells you which annotated coding sequences resemble known AMR, virulence, mobile, plasmid or phage-associated entries. It does not by itself show whether those genes sit inside a larger resistance island or other compound locus.

Compound loci need separate screening

BACTolomew keeps compound-locus FASTA catalogs separate so larger reference elements can be searched across complete assemblies instead of being reduced to isolated gene calls.

Structure needs two views

Core SNP phylogeny captures clonal relatedness, while Roary and Panaroo recover accessory genome structure. Hospital AMR interpretation usually needs both vertical and horizontal signals.

Practical compute claim

The defensible claim is not that every analysis is lightweight, but that BACTolomew is more deployable on modest infrastructure because it is modular, assembly-first, and can avoid optional heavy branches when they are not required.
